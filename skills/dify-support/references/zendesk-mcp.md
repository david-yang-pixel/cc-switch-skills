# Zendesk Route Compatibility Note

The active Zendesk workflow is [ticket access and actions](ticket-access-and-actions.md).

Use only OpenConnector `custom_mcp` connection `zendesk`. Do not call a direct Zendesk MCP namespace or endpoint. Zendesk Help Center actions are excluded as official or supporting sources. Public replies are unavailable; notes, status, metadata, and other writes require explicit action-specific authorization and readback verification.
